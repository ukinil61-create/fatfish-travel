# 大肥鱼的旅行 · 交接说明（第二版）

主角改名为「大肥鱼」（原「汐汐」），仿《旅行青蛙》的单文件网页放置游戏，配套两条宣传视频。

## 交付内容
| 路径 | 内容 |
|---|---|
| `游戏/大肥鱼的旅行.html` | 成品游戏，单文件约 3MB（美术为 webp、BGM 为 mp3，都已内嵌），离线可玩 |
| `游戏/补画的三张背景/` | 素材包里缺少的 `bg_coral` `bg_library` `bg_fjord`，这三张是我用程序画的 |
| `视频/大肥鱼的旅行_横屏.mp4` | 1920×1080，2:10，30fps |
| `视频/大肥鱼的旅行_竖屏.mp4` | 1080×1920，1:12，30fps |
| `封面/` | 横屏 16:10 与 1920×1080 两张，竖屏 3:4 一张 |
| `B站投稿文案.md` | 标题、简介、标签、分区 |
| `源码与素材.zip` | 全部源码、处理后的美术、作曲与视频渲染脚本 |

## 这一版做了什么
**美术接入**
- 小屋和海滩换成美术背景。小屋会按真实时间切换昼夜：22 点到 6 点是夜景，她会抱着鲸鱼玩偶睡觉。
- 她在家会轮流看书、缝纫、吃饭团、写日记、擦窗户、打盹。点她会蹦一下，并说一句和当前动作有关的话。
- 背包收拾好后，她会戴上草帽挥手说「我出发啦～」，然后转身走向门口淡出。
- 明信片换成美术背景合成：
  - 每个地点有专属姿势，角色会按场景打光（夜景偏冷，夕阳加暖色轮廓光）。
  - 叠加雨、雪、萤火虫、气泡、星砂等特效。
  - 神社场景会撑伞，森林场景有提灯。
- 明信片可以翻到背面看手写信。

**新玩法**
- **访客**：在海滩的野餐垫上放食物，会吸引不同的朋友：
  - 海苔饭团 → 寄居蟹「阿壳」
  - 鱼糕便当 → 海鸥「咕咕」
  - 珍珠奶茶 → 海豹宝宝「年糕」

  招待后会得到回礼（贝壳或福引券），好感度加一。认识的朋友之后会随机陪她旅行，出现在明信片里。三位朋友的人设由我拟定，你可以替换。
- **海风福引**：每次旅行回来会带一张福引券，在商店转福引。金球、红球、蓝球、白球分别对应布丁、道具、便当和贝壳。
- **纪念品**：每个地点 3 种（普通 / 少见 / 稀有），共 27 种，宝物架会显示收集进度和朋友的好感度。
- **声音**：WebAudio 合成音效，加一段 60 秒的原创循环 BGM。右上角「♪」可以开关。
- **其他**：加了开场欢迎对话；旧存档（`xixi-travel-v1`）会自动迁移，旧文案里的「汐汐」换成「大肥鱼」。

**素材处理**
- `xixi_read.png` 原图是黑底，我抠掉了黑底，并补了和其他立绘一致的深蓝描边。
- 所有立绘的半透明底噪都做了清理，透明度统一。
- 立绘大小按头身比例校正过：坐姿的原图画得比站姿大，缩放后头的大小保持一致。

## 构建
```
cd game
python3 build.py                      # → dist/fatfish-travel.html（独立网页版）
python3 build.py out.html --artifact  # → 发布到 claude.ai 用的版本（去掉 doctype/html/head/body）
```
`build.py` 会读取 `gassets/*.webp`、`art/pose_meta.json` 和 `gassets/bgm.mp3`，内联 `friends.js` 与 `svg_souv.js`。

## 视频与音乐的重新生成
1. 作曲：运行 `music/music.py` 生成 MIDI，再用 FluidSynth + FluidR3_GM 音色库渲染，之后做 loudnorm 响度标准化。
   横竖两版都以 96 BPM 为准，一小节 2.5 秒，画面切点和小节线对齐。
2. 录游戏画面：先运行 `film/record_gp.js` 录制实机画面，再用 ffmpeg 转成 30fps 序列，放到 `film/gp/`。
3. 导出明信片：运行 `film/export_cards.js`，导出视频结尾拼贴用的 9 张明信片。
4. 渲染与合成：
   - 在 `work/` 目录启动 `python3 -m http.server 8765`。
   - 运行 `node film/render.js h 4` 和 `node film/render.js v 4`，逐帧渲染出 JPEG 序列。
   - 运行 `python3 film/sfx.py h|v` 生成音效，最后用 ffmpeg 混音并编码。
5. `film/film.html` 是确定性的画布渲染器：`renderFrame(t)` 只依赖时间 t，分镜都写在 `buildShots()` 里。

## 已知的不足和下一步
1. **补画的三张背景**（珊瑚礁、云上图书馆、鲸歌峡湾）是程序绘制的，画风比 AI 美术简单。
   建议用原提示词清单第 15、19、20 条重新生成后替换 `art/bg/` 和 `gassets/`，然后重新 build。
   鲸歌峡湾在视频里拆成了「无尾巴背景 + 鲸尾图层」做升起动画。重画时最好也出一张无鲸尾版，并单独出一张透明底的鲸尾。
2. **朋友的形象**是 SVG 矢量小动物，风格比立绘扁平。如果要和立绘统一，可以按同样的提示词格式补三张朋友立绘。
3. 原来的低分辨率 `chara.png` 已经不再使用。
4. 可以继续做：朋友单独的旅行明信片、季节活动、更多地点。
